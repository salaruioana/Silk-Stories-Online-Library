# Silk Stories Library

A full-stack web application for managing a virtual library, developed as a university project. The application provides user authentication, shopping cart functionality, administrative features, and secure server-side operations.

## Technologies

- **HTML5**
- **CSS3**
- **JavaScript**
- **Node.js**
- **Express.js**
- **MySQL**
- **JSON**
- **Sessions & Cookies**

## Features

- User registration and authentication
- Session and cookie management
- Virtual library with book browsing
- Add-to-cart and shopping cart management
- Administrator role and administrative functionality
- Asynchronous JSON-based operations
- Server-side security mechanisms
- Responsive and user-friendly interface
